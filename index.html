Solve Endpoint

POST
http://203.161.41.146:5000/solve

Request Body

{ "key": "your_api_key", "prompt": "Click the star", "image": "base64_encoded_image" }
Parameter Type Required Description
key string Yes Your API authentication key
prompt string Yes The challenge prompt to solve
image string Yes Base64 encoded image of the challenge

Usage Examples

Python

import requests import base64 # Read image and encode to base64 with open("captcha.png", "rb") as image_file: image_b64 = base64.b64encode(image_file.read()).decode() response = requests.post( "http://203.161.41.146:5000/solve", json={ "key": "your_api_key_here", "prompt": "Click the star", "image": image_b64 } ) print(response.json())

JavaScript

const fs = require('fs'); // Read image and convert to base64 const imageBuffer = fs.readFileSync('captcha.png'); const imageBase64 = imageBuffer.toString('base64'); fetch('http://203.161.41.146:5000/solve', { method: 'POST', headers: { 'Content-Type': 'application/json', }, body: JSON.stringify({ key: 'your_api_key_here', prompt: 'Click the star', image: imageBase64 }) }) .then(response => response.json()) .then(data => console.log(data));

cURL

curl -X POST http://203.161.41.146:5000/solve \ -H "Content-Type: application/json" \ -d '{ "key": "your_api_key_here", "prompt": "Click the star", "image": "$(base64 -i captcha.png)" }'
